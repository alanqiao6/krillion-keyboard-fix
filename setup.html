Puffer Party Keyboard Fix

Keeps the category and everyone's answers on screen while you type in Krillion. Four steps, about two minutes, once.

  • Do this on your iPhone
  • Use Safari

  1. Get the Userscripts app

    Free on the App Store. Open it once after it installs, then come back here.

    Open the App Store

  2. Turn it on in Settings

    Go to Settings → Apps → Safari → Extensions → Userscripts and switch on Allow Extension.

  3. Install the fix

    The button opens the script. Then tap the page menu at the left of the address bar, choose Userscripts, and tap Install.

    Open the script

  4. Allow it on Krillion

    On krillion.io, open the page menu → Userscripts → Always Allow on This Website. Then reload the page. This step is the one people miss.

    Open Puffer Party

How to tell it's working

In a round, tap the answer box. The category shrinks to one line at the top, the top bar and banner ad step aside, and the answer box sits right on the keyboard.

Not working?
  • Reload krillion.io. Scripts only load when the page loads.
  • Check Settings → Apps → Safari → Extensions → Userscripts: under Permissions, krillion.io should say Allow.
  • On krillion.io, open the page menu → Userscripts. Krillion Keyboard Fix should be listed and switched on.
  • It only works in Safari. Chrome and other iPhone browsers don't support extensions.
  • To get a newer version later: page menu → Userscripts → Check for updates.
